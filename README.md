# מתמטיקה ב׳ (CLB)

מרצה: ד״ר שי צבאן · אחראי אקדמי: ד״ר אסף שריג

## עמוד ראשי

[`index.html`](index.html) — אינדקס הקורס, עם קישורים לכל הפרקים ותת-הפרקים.

באתר החי: https://shaytsaban.github.io/clb-mathematics-b/

בנוסף, [`files/formula-sheet.pdf`](files/formula-sheet.pdf) הוא דף נוסחאות מרוכז לכל הקורס (עמוד אחד), ומקושר להורדה מהעמוד הראשי, מיד מתחת ליומן השיעורים. הנוסחאות בו נבדקו ותואמו מול התוכן בפועל של כל תת-הפרקים.
